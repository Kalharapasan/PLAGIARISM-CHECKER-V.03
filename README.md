# Plagiarism Checker Pro - Complete Suite

A comprehensive plagiarism detection system with multiple interface options and detection algorithms.

## 🚀 Features

### Multiple Interfaces
- **Command Line Interface (CLI)** - For automation and scripting
- **Basic GUI** - Simple desktop interface for students
- **Advanced GUI** - Professional interface for educators
- **Ultimate GUI** - Enterprise-grade interface with all features

### Detection Algorithms
1. **Basic Engine** - Cosine Similarity
2. **Advanced Engine** - 4 algorithms (Cosine, Jaccard, N-gram, Sequence)
3. **Ultimate Engine** - 10+ algorithms including ML features

### File Support
- TXT, DOCX, PDF, RTF, HTML, Markdown, LaTeX, ODT, EPUB

### Database Features
- SQLite database with full-text search
- Reference document management
- Check history tracking
- Category-based organization
